# Refrankenstein 🧟

Refranes en galego, castellano, català y euskera: refrán del día, aleatorio, mezcla de mitades, buscador, favoritos y anatomía.

Es una web estática: un solo `index.html`, sin base de datos ni nada que compilar.
Los favoritos (♥) y las mezclas guardadas se quedan en el navegador de cada persona.

Para añadir refranes, se editan dentro de `index.html` (bloque `DATA`).

## Subirlo

1. **GitHub**: **+** → **New repository** → nombre `refrankenstein` → **Create repository**.
   Pulsa **uploading an existing file**, arrastra `index.html` y `README.md` y pulsa **Commit changes**.
2. **Vercel**: **Add New…** → **Project** → elige `refrankenstein` → **Import**.
   Deja **Other** en *Framework Preset* y pulsa **Deploy**.
